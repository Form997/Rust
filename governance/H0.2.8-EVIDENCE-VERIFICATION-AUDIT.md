# H0.2.8 — Evidence Verification & Audit Chain

**Status:** Implemented as a local verification foundation on this development branch; review and CI required.
**Parent:** H0.2.7, merged into `h0-2-6-rulebook-enforcement-core`.

## Purpose

H0.2.7 binds each approved control to a signed evidence record. H0.2.8 adds local artifact digest verification, consistency checks for CI run/job metadata, expiry and revocation rejection, and a tamper-evident JSONL audit chain.

## Evidence manifest

The manifest schema records:
- stable evidence ID and artifact path/SHA-256;
- repository, commit SHA, workflow run ID, job ID, workflow name and successful conclusion;
- canonical GitHub Actions run URL and observation timestamp;
- expiry and optional revocation timestamp/reason.

The verifier hashes actual artifact bytes and compares SHA-256. It rejects mismatched repositories, malformed commit IDs, unsuccessful jobs, inconsistent run URLs, expired evidence and revoked evidence.

## Audit chain

Each JSONL entry has a sequence, previous-record hash, event payload and SHA-256 record hash. Verification detects edits, deletions, reordering and broken links. Appending first verifies the existing chain.

## Critical trust boundary

CI metadata is a locally supplied snapshot. This phase checks internal consistency but does **not** cryptographically authenticate that snapshot against GitHub, prove a workflow/job actually ran, or verify a GitHub artifact attestation. A trusted collector/API integration and/or GitHub artifact-attestation verification is a later phase.

A hash chain stored only on the same writable disk is tamper-evident, not immutable: an attacker able to rewrite the entire ledger can recompute it. Production must anchor the latest ledger hash in separately protected storage, enforce append-only permissions, and back up the ledger.

The evidence verifier is not yet automatically invoked by every subsystem gate. Actual compiler/runtime/AI/training/evaluation/scientific/release integration remains a separate required milestone. No production deployment, external certification, or exclusive-owner enforcement is claimed.
